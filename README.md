## 🌟 About Spira

Spira Network is an innovative Web3 social platform designed to empower regenerative communities in Latin America. By leveraging blockchain technology and circular economy principles, Spira aims to foster local impact and create a more connected, sustainable future.

## 🚀 Key Features

-   Interactive map for visualizing local events and community "nodes"
-   Blockchain-based attestations for verifying activities and building trust
-   Integration with Base for transparent, on-chain interactions
-   Reputation system based on verifiable community contributions
-   Framework for measuring and displaying collective impact metrics
-   Content organized around 12 organic areas of being for holistic community development

## 🛠 Technologies Used

-   Frontend: Next.js, React, TailwindCSS
-   Backend: Next.js API Routes
-   Database: PostgreSQL with Drizzle ORM
-   Blockchain: Base (Ethereum L2)
-   Web3 Integration: Coinbase Wallet SDK, wagmi
-   Attestations: Ethereum Attestation Service (EAS)

## 🌱 Why Spira for LATAM?

Latin America is rich in natural resources, ancestral wisdom, and innovative potential. Spira Network addresses the urgent need to reimagine how communities connect and collaborate in a world facing multiple crises. By providing a decentralized platform that respects cultural heritage and promotes regenerative practices, Spira aims to catalyze positive change across the region.

## 🔧 Setup and Installation

1. Clone the repository:
    ```
    git clone https://github.com/your-username/spira-network.git
    ```
2. Install dependencies:
    ```
    cd spira-network
    npm install
    ```
3. Set up environment variables (see `.env.example`)
4. Run the development server:
    ```
    npm run dev
    ```
